# 🐶 TinDog Landing Page

A modern and responsive landing page for a fictional dog dating app called **TinDog** 🐾.
This project was built as part of a web development course and showcases front-end design using Bootstrap.

---

## 🚀 Live Demo

👉 https://chris1-dev.github.io/Tindog

## 🛠️ Built With

* HTML5
* CSS3
* Bootstrap 5

---

## 💡 Features

* Responsive design (mobile-first 📱)
* Clean and modern UI
* Pricing section with cards
* Testimonials section
* Hero section with call-to-action buttons
